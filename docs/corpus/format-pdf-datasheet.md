# PDF datasheet checklist

## Page budget
A datasheet is one or two pages. If the content does not fit, the datasheet is summarising too much; link to a full specification instead.

## Specification table
Put the key specifications in one table with units in the header row. Order rows by what buyers compare first, and never mix units within a column.

## Print and file hygiene
Use print-safe colours with sufficient contrast, embed fonts, and keep the file under five megabytes. Set the document title in the file properties.

## Versioning
Add a footer with the version, the publication date and where to find the latest edition. Outdated datasheets circulate for years.
