# Writing for beginners

## Define every term once
A beginner stops at the first unexplained word. Define each technical term the first time it appears, in one plain sentence, and keep using the same word afterwards instead of a synonym.

## One idea per section
Give each section a single concept and a single takeaway. If a section needs two diagrams to explain, it is two sections.

## Examples before abstractions
Start from a familiar, concrete example and only then generalise. A worked example with each step numbered is easier to follow than a paragraph describing the steps.

## Close with next steps
End with what the reader can now do and one suggested next piece to read. Beginners who know where to go next keep going.
