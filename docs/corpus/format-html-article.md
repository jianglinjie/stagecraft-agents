# HTML article checklist

## Structure and headings
Use exactly one top-level heading for the title and nest section headings in order without skipping levels. Screen readers and search engines both navigate by this outline.

## Length and reading time
Most articles work best between 800 and 1,500 words. Show an estimated reading time near the title, and split anything longer into a series.

## Metadata
Write a meta description under 160 characters that states what the reader will learn. Give the page a canonical URL and an image with a meaningful alternative text for link previews.

## Links and media
Use descriptive link text instead of "click here". Every image needs alternative text, and embedded video needs captions.
